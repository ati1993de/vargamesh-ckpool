# Security Policy

Never commit or publish:

- RPC passwords
- RPC cookies
- bridge secrets
- wallet private keys
- WIF private keys
- wallet files
- seed material
- SSH private keys
- TLS private keys
- miner IP logs
- production environment files
- webhook or API credentials

The VargaMesh Core JSON-RPC interface should normally remain bound to
localhost.

Report security issues privately to the project maintainer before public
disclosure where appropriate.
